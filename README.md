Entry for the make.fun bounty **"Ridiculous at First Glance, Real by the Second"** — one sentence pitching a bizarre startup idea that sounds absurd until you realise it would actually sell.

## The pitch

> We rent retired racehorses to offices as emotional-support stallions: companies pay $400 a day because a 500-kilo horse in the lobby ends every pointless meeting in five minutes flat.

## How to run

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (one sentence, 200 characters at most). Python standard library only; deterministic — run it twice and the output is byte-identical.
